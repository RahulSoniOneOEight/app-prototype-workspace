# App Prototype Workspace

Reusable workspace for building application prototypes from text briefs, GitHub references, and connected Penpot files using OpenCode, DeepSeek/OpenAI, Penpot AI Kit, and Penpot MCP.

## Prototype workflow

1. Capture the product brief in `brief/product-brief.md`.
2. Add design/code references under `references/`.
3. Define personas, journeys, and the screen map under `ux/`.
4. Record design foundations, components, and decisions under `design/`.
5. Use `prompts/prototype-master-prompt.md` as the standard OpenCode prototype workflow.
6. Build and iterate the visual prototype in Penpot through Penpot MCP.

Production application code should be added only after Prototype v1 is approved.
