# Client Experience Directions

Create 2–3 materially different product directions here when product exploration is useful.

Use `experience-directions/templates/` as strategy seeds, but tailor each direction to the client profile and active presets.

Directions should vary meaningful product dimensions such as structure, journeys, patterns, density, merchandising, interactions, and visual/resource strategy. Do not create superficial color-only alternatives.

After client review, capture the selected/mixed experience in `../approved-experience.yaml` (or start from `../approved-experience.example.yaml`).
