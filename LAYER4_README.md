# Layer 4 — Reusable Agency Intelligence

Layer 4 contains client-agnostic reusable knowledge and implementation seeds.

- `presets/` = recommendations by business model, industry, use case and visual direction.
- `design-contract/` = reusable UX/UI capability contracts.
- `experience-patterns/` = strategic product archetypes.
- `resources/` = approved source/provider/resource intelligence and provenance policy.
- `intelligence-registry/` = compact discovery indexes for OpenCode.
- `packages/agency_flutter_ui/` = representative reusable implementation.

## Promotion rule

Client-specific work stays in the client workspace until it proves reusable. Promotion means: extract → normalize → add metadata → review → contract → implementation. Do not copy client branding or one-off rules into Layer 4.

## Seed provenance

This milestone is seeded from the B2C+B2B marketplace reference prototype and the approved platform/visual-direction specifications. It is a normalized knowledge seed, not a copy of the reference application.
